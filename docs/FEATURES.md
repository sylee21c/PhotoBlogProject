# 추가 개발과 확인 방법

Android 1.1은 기존 수업 API와 UI 업로드를 유지하면서 다음 기능을 추가했습니다. 모든 동작은 실제 Django 서버를 대상으로 합니다.

## 검색과 추가 조회

제목 또는 본문의 검색어를 입력하고 검색을 누릅니다. 정렬을 변경하면 첫 페이지부터 다시 조회합니다. 결과가 12장보다 많으면 하단의 다음 사진 더 불러오기로 추가 조회합니다. 중복 ID를 제거하고 응답 순서가 뒤바뀌면 최신 요청만 화면에 반영합니다.

`GET /api_root/Post/`는 수업 자료와 같은 배열 응답입니다. `?page=1&page_size=12`를 지정할 때만 `count`, `next`, `previous`, `results`를 반환합니다. 페이지 크기는 최대 30입니다. 페이지 번호는 갱신 도중 게시글이 추가·삭제되면 달라질 수 있으므로 최신 전체 상태는 동기화로 다시 받습니다.

## 본인 게시글 수정과 삭제

로그인하면 본인 카드에 수정·삭제 버튼이 나타납니다. 수정에서는 제목과 내용을 바꿉니다. 삭제는 확인 창에서 취소할 수 있습니다. 웹 상세 화면도 같은 기능을 제공하며 웹 편집에서는 사진을 교체할 수 있습니다.

버튼 표시와 별개로 서버가 실제 작성자 권한을 검사합니다. 웹 변경 요청에는 CSRF 토큰이 필요합니다. 삭제 또는 사진 교체가 DB에 커밋된 다음 사용하지 않는 기존 파일을 정리합니다. 다른 글이 같은 파일을 참조하면 보존하고, DB 삭제가 롤백되면 사진도 보존합니다. 운영 저장소 장애로 파일 정리가 실패하면 이미 커밋된 글 변경을 취소할 수는 없으므로 배포 환경에서 저장소 로그를 확인해야 합니다.

## 오프라인 갤러리와 즐겨찾기

조회가 성공할 때 마지막 목록과 검색·정렬·페이지 상태를 디스크에 저장합니다. 받은 이미지도 기기에 보관합니다. 앱을 종료한 뒤 서버 연결이 없어도 저장된 목록과 사진을 복원합니다. 동기화가 실패해도 기존 사진을 지우지 않으며 다시 시도할 수 있습니다. 즐겨찾기는 서버 주소와 게시글 ID별로 저장합니다.

목록은 4 MB, 사진은 32 MB 한도로 오래 사용하지 않은 캐시부터 정리합니다. 저장되지 않았거나 운영체제가 캐시를 지운 사진은 오프라인에서 표시할 수 없습니다. 즐겨찾기 필터는 현재 불러온 목록에 적용되므로 전체 사진이 필요하면 다음 페이지를 먼저 불러옵니다. 업로드·수정·삭제는 서버 연결이 필요합니다.

## 작성 중인 초안 복원

시스템 사진 선택기에서 선택한 사진의 읽기 권한과 제목·본문을 보관합니다. 닫기 버튼으로 나와 앱을 재실행한 다음 새 사진 게시와 초안 이어쓰기를 누릅니다. 사진 미리보기와 입력한 내용이 복원됩니다. 게시 성공 또는 초안 삭제를 누르면 지워집니다. 초안은 서버별 하나입니다. 원본 사진이 삭제되거나 제공자가 읽기 권한을 회수하면 다른 사진을 선택해야 합니다.

## 연결과 계정

설정에서 서버 주소, 연결 확인, 로그인·로그아웃을 제공합니다. `/api/me/`에서 계정 ID를 확인해 본인 게시글 관리 UI를 표시합니다. 토큰은 AES-256-GCM 암호문으로 앱 전용 저장소에 보관하고 암호화 키는 Android Keystore에서 관리합니다. 암호화의 추가 인증 데이터에는 서버 주소를 넣습니다. 주소를 변경하면 이전 토큰을 삭제하고 다시 로그인합니다. 기존 평문 토큰은 로드 시 암호문으로 이전합니다. 비밀번호는 보관하지 않습니다.

## 회귀 검증

`scripts/test.ps1`은 독립 테스트 DB에서 서버를 검증합니다. Android 빌드 시 Java HTTP/multipart 및 디스크 캐시 단위 테스트를 실행합니다. `scripts/verify_extended_android.py`는 실제 AVD에서 다음 순서로 실행합니다.

```powershell
.\.venv\Scripts\python.exe scripts/verify_extended_android.py --phase prepare
.\.venv\Scripts\python.exe scripts/verify_extended_android.py --phase pagination
.\.venv\Scripts\python.exe scripts/verify_extended_android.py --phase crud
.\.venv\Scripts\python.exe scripts/verify_extended_android.py --phase draft
.\.venv\Scripts\python.exe scripts/verify_extended_android.py --phase offline
```

전용 에뮬레이터 앱 데이터 초기화와 `V2Fixture` 테스트 게시글 재생성이 포함됩니다. 개인정보가 있는 기기에 실행하지 않습니다. 오프라인 검증은 에뮬레이터 Wi-Fi와 모바일 데이터를 일시적으로 끈 뒤 복원합니다. 결과는 `evidence/android-extended.json`, 실제 캡처는 `evidence/screenshots/14-*.png`에 기록합니다.
